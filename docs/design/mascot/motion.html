omg.dev mascot — motion prototype · Direction G, morphing pure eye

Direction B's anatomy (cream orb, one dark pupil, no body parts) taken into motion: the eye stays constant, the body's silhouette is each bot's identity, and the silhouette continuously, organically morphs. Everything below is live — inline SVG paths re-computed every frame, no video, no image assets.

Reduced motion is enabled in your OS/browser — breathing, blinking, mouse parallax and auto-cycling are paused and every creature is shown in a static idle pose. State-theater buttons still work but snap instantly instead of springing.

1 · Home shapes

Same eye, five silhouettes — circle, squircle, teardrop, pebble, hexagon. Each idles on its own 6–9s breathing loop with its own phase offset, so the row never falls into lockstep, and each blinks on its own randomized timer. Each also carries its own colorway (circle keeps the warm default; squircle, teardrop, pebble and hexagon sample Brand, Violet, Forest and Midnight) — shape and color compose into one identity, the way a bot roster would show it.

2 · State theater

One creature, five states, expressed entirely as deformation of the same body — no icon ever swaps. Every transition uses a spring-style overshoot easing (squash past the target, then settle).

Idle — slow organic breathing, pupil resting upper-right.

3 · Morph demo

One creature, auto-cycling through all five home shapes in sequence. Each shape is expressed on the same 12-point silhouette, so the interpolation reads as one body changing pose rather than an icon swap. 4 · Pupil life

Move the cursor anywhere on this page — every creature above and below drifts its pupil toward it with soft parallax (distance-clamped, gently lerped, never a snap). Blinks are a lid ellipse scaling shut over the pupil, not an opacity fade.

5 · Survives small

Circle home-shape at 64 / 32 / 16px. Breathing survives all three sizes. Below ~24px, pupil parallax, independent per-creature blink timers and full path-wobble are dropped in favor of one cheap CSS scale-breathe — at 16px that geometric detail doesn't read anyway, so paying for it is wasted work.

Direction G prototype for Bot Mode. Body morph: 12-point Catmull-Rom blob, radii re-sampled every frame (idle wobble, state targets, spring overshoot via easeOutBack) and written to a single SVG path d attribute. Pupil/lid: a single translate() on one group per creature plus a lid-ellipse scaleY — both compositor-cheap, no filters, no layout reads in the animation loop (bounding-box centers for mouse parallax are cached on load/resize, not read per frame). Each Creature exposes a destroy() that clears its blink timer and unregisters it from the tick loop — groundwork for porting this into a reusable component.
