# StoreKit testing

`omg.storekit` is an Xcode StoreKit configuration file. It lets the purchase
flow run against a local, fake App Store — no App Store Connect entry, no
sandbox Apple ID, no signed build uploaded anywhere.

It lives here and not in `ios/` because `ios/` is generated by `expo prebuild`
and is gitignored. Anything put there is deleted by the next prebuild.

## What it is NOT

It is not proof that a purchase works. A StoreKit-config transaction is signed
by a **local test certificate**, so the JWS it produces does not verify against
Apple's real root CAs — which is exactly what
`control-plane/lib/app-store-billing.ts` checks. Submitting one to omg
produces `invalid App Store transaction`, correctly.

So this exercises: product listing, Apple's price strings, the purchase sheet,
cancellation, restore, and every UI state around them. It does not exercise
end-to-end entitlement. That needs a real signed build plus a sandbox Apple ID,
and there is no way around it.

## Using it

The config attaches to a **scheme**, so it needs a native build — it cannot be
turned on for an already-installed dev client:

```bash
cd mobile
npx expo prebuild --platform ios     # regenerates ios/
open ios/omg.xcworkspace
```

In Xcode: Product → Scheme → Edit Scheme → Run → Options → StoreKit
Configuration → `../storekit/omg.storekit`. Then run to the simulator.

Transactions are managed from Debug → StoreKit → Manage Transactions.

## Prices here are illustrative

They sit roughly 20% above the web prices in `apps/web/src/lib/billing.ts`, to
absorb Apple's commission. The REAL prices come from App Store Connect and are
per-storefront. Nothing in the app hardcodes a price: it renders StoreKit's
`displayPrice` verbatim. Editing a number here changes only what the simulator
shows.

## Seeing the paywall without any of this

Every UI state can be driven without a native build at all, via the mock store
in `src/omg/store.ts`:

```bash
EXPO_PUBLIC_OMG_IAP_MOCK=1            npx expo start   # products load and buy
EXPO_PUBLIC_OMG_IAP_MOCK=empty        npx expo start   # store returns nothing
EXPO_PUBLIC_OMG_IAP_MOCK=error        npx expo start   # store fails to load
EXPO_PUBLIC_OMG_IAP_MOCK=cancel       npx expo start   # user dismisses the sheet
EXPO_PUBLIC_OMG_IAP_MOCK=purchasefail npx expo start   # purchase fails
EXPO_PUBLIC_OMG_IAP_MOCK=owned        npx expo start   # restore finds a subscription
```

The mock never produces a usable signed transaction and the banner across the
top of the paywall says so. It is off unless the env var is set, so it cannot
reach a release build.
