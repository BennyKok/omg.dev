# Speech fixture

`whistle-jfk.wav` contains an 11-second excerpt from John F. Kennedy's 1961
inaugural address. The simulator fixture uses this public-domain speech instead
of a physical microphone. It is 16 kHz mono PCM16 WAV.

SHA-256: `13f2ca57b38d7feda51a0e623612cefffe67238c69b1fbd49fef6ee7e0209ec0`.

The audio fixture disables cloud fallback. Success requires the native engine
to return the speech text. It does not verify a real iPhone microphone.
